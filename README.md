# ReadLigero
Offline PWA reader (PDF / EPUB / FB2 / TXT) with vocabulary highlighting and flashcard quizzes.
Serve this folder over HTTPS (or http://localhost), e.g. `npx serve .` or `python3 -m http.server`, then open index.html and install it.
Bundled libraries: Dexie 3.2.7, pdf.js 3.11.174, JSZip 3.10.1, epub.js 0.3.93.
